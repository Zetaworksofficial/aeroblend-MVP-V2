# AEROBLEND

> Hydration, reimagined.

AeroBlend is a premium botanical beverage concept built around a clean, editorial-first digital experience.

This project is a frontend-focused landing page designed to explore typography, visual hierarchy, product storytelling, responsive layouts, and subtle interaction design.

---

## Live

🌐 **Website:** https://aeroblend.netlify.app

📦 **Repository:** https://github.com/zetaworksofficial/aeroblend-MVP-V2

---

## What I Built

The goal was to move away from the typical "startup landing page" look and build something more restrained and intentional.

The website focuses on:

- Strong typography
- Generous whitespace
- Editorial-style layouts
- Product-focused photography
- Minimal navigation
- Responsive design
- Subtle scroll-based animations
- Clear visual hierarchy
- Original AeroBlend branding and content

---

## Sections

### Hero
A minimal introduction to AeroBlend with a large product visual and concise positioning.

### Product
Introduces the concept behind AeroBlend and its approach to hydration.

### Flavors
Three featured blends:

- Charred Rainwater
- Nutty Caramel Smoke
- Briny Floral Chill

### Ingredients
Six featured botanical ingredients:

- Amla
- Spirulina
- Giloy
- Tulsi
- Aloe Vera
- Coconut Water

### Story
A short brand narrative focused on the product's visual and conceptual identity.

### Final CTA
A simple closing section designed to leave the user with the brand's central idea.

---

## Design Direction

The visual language is intentionally:

- Minimal
- Earthy
- Editorial
- Premium
- Typography-driven
- Product-focused

The layout takes inspiration from modern technology and editorial websites while keeping AeroBlend's branding, copy, imagery, and identity original.

---

## Tech

Built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive CSS
- Intersection Observer API
- Git
- GitHub
- Netlify

No frontend framework is currently used.

The project is intentionally lightweight and dependency-free.
